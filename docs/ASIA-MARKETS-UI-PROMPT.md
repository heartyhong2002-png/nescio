# 화면·사용성 세션용 — 1차 아시아 시장 UI

Nescio 홈의 시장 지수 영역을 개선해 주세요. 이번 작업의 대상은 **화면과 사용성뿐**입니다. 시세 수집 로직, 외부 API, 캐시·타임아웃, API 응답 형식은 변경하지 마세요.

## 배경

홈은 국내 시장과 함께 1차 해외 시장으로 일본·중국·대만의 대표지수를 보여줍니다.

- 일본: `니케이225` (`🇯🇵`)
- 중국: `상해종합`, `심천종합` (`🇨🇳`)
- 대만: `대만가권` (`🇹🇼`)

현재 핵심 화면 파일은 `src/app/page.tsx`이고, 기존 다크 인텔리전스 디자인 시스템과 `dashboard-index-*` CSS를 우선 재사용합니다. 모바일은 가로 스크롤이 가능한 카드 스트립을 유지해 숫자와 등락률이 잘리지 않게 하세요.

## 사용할 API 계약

지수 데이터는 아래 API에서 옵니다.

```ts
GET /api/market-indices?phase=indices

// 200
{
  indices: Array<{
    name: "코스피" | "코스닥" | "니케이225" | "상해종합" | "심천종합" | "대만가권" | "항셍지수";
    close: number | null;
    changeRate: number | null;
    asOf?: string; // ISO 시각 또는 KRX YYYYMMDD
    source?: "KIS" | "KRX" | "Yahoo";
  }>;
}
```

`indices`는 부분 성공을 허용합니다. 예를 들어 국내 2개만 오거나, 국내와 일본만 올 수 있습니다. 해외 공급자 실패를 API 오류로 간주하거나 재시도 버튼을 강요하지 마세요. 기존 AI 코멘트 요청은 별도 `GET /api/market-indices?phase=comment`이며, 지수 카드 UI와 독립적으로 유지해야 합니다.

## 구현 요구사항

1. 홈의 지수 영역을 `국내 시장`과 `아시아 시장`으로 명확히 구분하세요. 국내는 코스피·코스닥, 아시아는 일본·중국·대만 지수입니다. API가 주는 순서를 신뢰하지 말고 표시 순서는 `니케이225 → 상해종합 → 심천종합 → 대만가권`으로 고정하세요.
2. 카드는 현재가, 전일 대비율, 국가/시장 식별을 빠르게 읽을 수 있어야 합니다. 상승·하락 색상과 화살표에는 기존 `changeDirection`, `changeArrow`, `formatPrice`를 사용하고, 임의 시세·예시 수치를 넣지 마세요.
3. `asOf`와 `source`가 있는 경우 카드 또는 해당 섹션에 짧고 과하지 않게 기준 시각/출처를 표시하세요. `Yahoo`는 Yahoo Finance, `KIS`와 `KRX`는 기존 표기 규칙을 따릅니다. 서로 다른 시장의 기준 시각을 한 시각으로 단정하지 마세요.
4. 로딩 중에는 국내·아시아 영역의 실제 카드 형태를 닮은 스켈레톤을 보이세요. 부분 성공이면 수신된 카드만 보여주고, 아시아 지수가 하나도 없을 때는 국내 영역을 유지한 채 짧은 보조 안내만 보여주세요. 전체 지수가 비었을 때만 전체 빈 상태를 보여주세요.
5. 화면 폭이 좁아도 카드 제목, 지수, 등락률이 겹치거나 잘리지 않아야 합니다. 키보드·스크린리더 사용자가 섹션과 카드 내용을 이해할 수 있는 의미 있는 레이블을 제공하세요.
6. 기존 관심종목·장중 차트·AI 시장 코멘트의 요청 순서와 동작을 바꾸지 마세요. API 타입을 넓히거나 서버 코드를 수정해야 한다고 판단되면 구현 전에 컨트롤타워에 영향 범위를 알려주세요.

## 완료 조건

- 데스크톱과 모바일 폭에서 국내/아시아 구분, 긴 숫자, 부분 성공 상태를 확인한다.
- `npm run lint`와 `npm run build`를 통과한다.
- 최종 보고에 수정 파일, 화면에서 확인한 로딩·부분 실패·빈 데이터 상태를 짧게 적는다.
